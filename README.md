Sortir.com

Projet réalisé dans le cadre de ma formation Développeur Web et Web Mobile à l'ENI.

Sortir.com est une application web permettant aux étudiants d'un campus de consulter, créer et gérer des sorties et activités.

🛠️ Technologies


PHP / Symfony
Doctrine ORM
Twig
MySQL
Bootstrap
JavaScript
Git / GitHub

✨ Fonctionnalités

Gestion des utilisateurs
Création et gestion de sorties
Inscription / désinscription aux sorties
Recherche et filtrage des sorties
Gestion des lieux et des villes
Gestion des différents états d'une sortie
Formulaires Symfony et validation des données
Interface responsive

👨‍💻 Projet réalisé en équipe

Ce projet m'a permis de travailler sur l'architecture Symfony, les entités et relations Doctrine, les contrôleurs, les formulaires, les templates Twig ainsi que la gestion de données en base de données.
